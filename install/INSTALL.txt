PS4 Overlay - Installation
==========================

Files
  ps4_overlay_plugin.sprx   the plugin
  ovl_config.ini            settings (the in-game menu can save to it)
  plugins.ini.example       auto-load entry for GoldHEN
  README.md                 notes

Install
  1. Copy ps4_overlay_plugin.sprx to       /data/GoldHEN/plugins/
  2. Create the folder                     /data/GoldHEN/plugins/ps4_overlay_plugin/
     and copy ovl_config.ini into it.
  3. Auto-launch: add the lines from plugins.ini.example to
     /data/GoldHEN/plugins.ini  ([default] = every game, [CUSAxxxxx] = one game).
  4. Start Minecraft. You should get a PS notification "PS4 Overlay - Starting. . .", then "Ready" once
     the first frame is drawn, plus an on-screen OVERLAY ACTIVE banner. Press Touchpad + Options for the menu.

Controls
  Touchpad + Options  show / hide menu (changeable in MENU > Open combo; the game never sees it)
  L1 / R1             previous / next tab
  D-pad up/down       select row
  D-pad left/right    change value
  Cross               toggle / cycle / run
  Circle              close menu
  While the menu is open the game does not receive pad input (MENU > Block input).

Minecraft test checklist
  - "Starting. . ." notification appears at launch        -> plugin loaded
  - "Ready" notification + banner after the world/menu draws -> render hook works
  - FPS box top-right while you play survival            -> overlay drawing works
  - Touchpad + Options opens the menu without pausing    -> pad hook works
  - "Failed to start" notification                       -> read ovl.log

If nothing appears
  Open /data/GoldHEN/plugins/ps4_overlay_plugin/ovl.log - it records every step
  (module loads, hooks). Send it along with a description of what you see.
  If the picture is scrambled where the menu should be, set render.layout to 1 or 2.
